# RITE — техническая спецификация

**Для исполнителя:** это полное задание на реализацию игры с нуля. Все числа в документе — окончательные. Ничего не додумывай: если параметр указан, используй его; если ситуация не описана — она описана в разделе 12 «Крайние случаи».

---

## 1. Что строим

Браузерный тактический роглайт. Игрок ведёт отряд из 6 фигур через 5 боёв против ИИ. Бой идёт на доске 8×8 по очереди. Каждые 3 хода игрок получает Карту Кармы, которая ломает базовые правила. Ран длится 5–7 минут, поражение приводит к мгновенному рестарту.

Ядро правил (ранги фигур, очки действий, атака ценой хода, повышение, Карты Кармы) взято из настольной игры Jedibo. Всё остальное — жанр Slice & Dice и Slay the Spire.

**Главный критерий качества — не полнота правил, а первые 30 секунд.** Человек открывает вкладку, делает три хода, убивает первую фигуру и не может закрыть. Если выбирать между дополнительной механикой и качеством отклика — всегда выбирается отклик.

### 1.1. Жёсткие ограничения

| Ограничение | Значение |
|---|---|
| Внешние ассеты | **Запрещены полностью.** Ни картинок, ни звуковых файлов, ни шрифтов с CDN |
| Графика | Только Canvas 2D: примитивы, градиенты, тени, партиклы |
| Звук | Только Web Audio API: осцилляторы, шум, огибающие, свёрточный ревер на сгенерированном импульсе |
| Шрифты | Только системные стеки |
| Зависимости в рантайме | Ноль |
| Сеть в рантайме | Ноль запросов |
| Сохранения | Нет. Закрыл вкладку — ран потерян |

## 2. Стек и структура файлов

TypeScript, Vite только как дев-сервер и сборщик. Никаких рантайм-зависимостей.

```
/
  index.html
  package.json          # vite + typescript, больше ничего
  tsconfig.json
  src/
    main.ts             # точка входа, game loop, ресайз канваса
    core/
      types.ts          # все типы и константы
      board.ts          # координаты, геометрия, проверки клеток
      rules.ts          # легальные ходы, атаки, повышение — чистые функции
      battle.ts         # состояние боя, применение действий, выдача событий
      cards.ts          # 5 карт: условия и эффекты
      ai.ts             # ИИ противника
      run.ts            # цепочка из 5 боёв, драфт, победа/поражение
    view/
      renderer.ts       # отрисовка доски, фигур, UI
      animator.ts       # очередь анимаций, твины, прерывание
      particles.ts      # системы партиклов
      camera.ts         # тряска, наезд, поворот
      scenes.ts         # вау-сцены: повышение, Линия смерти, Обстрел
    audio/
      synth.ts          # примитивы синтеза: шум, огибающие, ревер
      sfx.ts            # событие → звук
      music.ts          # процедурные слои
    input.ts            # мышь, тач, хоткеи
```

### 2.1. Архитектурный принцип — соблюдать строго

**Ядро правил не знает о рендере.** Всё в `core/` — чистые функции над состоянием. Применение действия возвращает новое состояние и **список событий**:

```ts
type BattleEvent =
  | { t: 'moved';     id: FigureId; from: Cell; to: Cell }
  | { t: 'killed';    id: FigureId; at: Cell; rank: Rank; side: Side }
  | { t: 'attacked';  id: FigureId; from: Cell; to: Cell }
  | { t: 'promoted';  id: FigureId; from: Rank; to: Rank; at: Cell; placedAt: Cell }
  | { t: 'apSpent';   left: number }
  | { t: 'cardDrawn'; card: CardId }
  | { t: 'cardPlayed';card: CardId; payload?: unknown }
  | { t: 'captured';  id: FigureId; at: Cell }
  | { t: 'turnEnded'; side: Side }
  | { t: 'battleWon' } | { t: 'battleLost' };
```

Слой представления подписывается на события и проигрывает сцены. Это даёт три вещи: правила тестируются юнит-тестами без канваса, тайминги меняются без риска для логики, ИИ гоняет то же ядро.

**Логика никогда не ждёт анимацию.** Состояние меняется мгновенно, анимации — очередь визуализации поверх. Ввод блокируется только на время вау-сцен (раздел 9.4).

## 3. Правила боя

### 3.1. Доска и координаты

- Доска 8×8. Клетка — `{x: 0..7, y: 0..7}`. `x` слева направо, `y` сверху вниз.
- **Игрок внизу**, его тыловой ряд — `y = 7`. **Враг вверху**, его тыловой ряд — `y = 0`.
- «Вперёд» для игрока — `dy = -1`, для врага — `dy = +1`. Обозначим это `f`.
- **Стартовая зона игрока** — ряды `y = 6, 7`. Резервный ряд — `y = 5`.
- **Линия повышения игрока** — `y = 0`. Линия повышения врага — `y = 7`.

### 3.2. Стартовая расстановка игрока

Фиксированная, выбора нет — пауза до первого хода убивает вау.

| Фигура | Клетки |
|---|---|
| Квадрат | (2,7), (5,7) |
| Треугольник | (2,6), (3,6), (4,6), (5,6) |

Круга в старте нет. **Круг можно получить только повышением** — это цель рана.

### 3.3. Очерёдность и ввод

- **Первым всегда ходит игрок.** Броска кубика на первый ход нет.
- Стороны ходят строго по очереди: игрок → враг → игрок → …
- «Ход игрока №N» — порядковый номер хода именно игрока в текущем бою, начиная с 1. Аналогично для врага. Счётчики обнуляются в начале каждого боя.
- Флаг «фигура уже действовала» сбрасывается у всех фигур стороны в начале её хода.
- У врага нет Карт Кармы. Единственное исключение — способность Проповедника (4.2).

**Ввод:**

| Действие игрока | Реакция |
|---|---|
| Клик по своей фигуре, которая ещё не действовала | Выбрать её, показать зоны хода и атаки |
| Клик по подсвеченной пустой клетке | Передвижение |
| Клик по подсвеченной клетке с фигурой врага | Атака |
| Клик по другой своей фигуре | Переключить выбор |
| Клик мимо / правая кнопка / Esc | Снять выбор |
| Клик по «Завершить ход» или клавиша Пробел | Завершить ход, если сделано ≥ 1 действие |
| Любой клик во время вау-сцены | Игнорируется |

Тач-ввод работает теми же правилами: тап вместо клика, наведения нет.

### 3.4. Очки действий

- В начале своего хода сторона получает **5 ОД**.
- Передвижение — **1 ОД**.
- Атака — **все оставшиеся ОД, ход немедленно завершается**.
- Каждая фигура за ход делает **не более одного действия** (снимается только Блицкригом).
- Сторона обязана совершить **хотя бы одно действие**. Кнопка «Завершить ход» неактивна, пока действий ноль.
- Ход завершается автоматически, если: ОД потрачены, совершена атака, или ни одного легального действия не осталось.
- **Таймеров нет.**

> Атака ценой всего хода — центральная механика. Не смягчать, не менять, не добавлять «дешёвую атаку». Всё напряжение игры держится на этом выборе.

### 3.5. Направления и дальность

Направление задаётся вектором `(dx, dy)`. Для стороны с «вперёд» `f`:

| Название | Вектор |
|---|---|
| вперёд | `(0, f)` |
| вперёд по диагонали | `(-1, f)`, `(1, f)` |
| в стороны | `(-1, 0)`, `(1, 0)` |
| назад по диагонали | `(-1, -f)`, `(1, -f)` |
| назад | `(0, -f)` |

| Ранг | Направления движения | Дальность | Направления атаки | Дальность атаки |
|---|---|---|---|---|
| Треугольник | вперёд | 1 | вперёд, вперёд по диагонали | 1 |
| Квадрат | вперёд, вперёд по диагонали, в стороны | 1–3 | те же | 1–3 |
| Круг | все 8 | 1–5 | все 8 | 1–5 |

**Правила пути (одинаковы для движения и атаки):**

- Движение только по прямой в одном из разрешённых направлений.
- Все клетки строго между стартом и целью должны быть **пусты**. Перепрыгивать нельзя ничего — ни свои фигуры, ни чужие (исключение: карта Прыгун, в этой версии отсутствует).
- Клетка назначения при движении — пуста.
- Клетка назначения при атаке — занята фигурой противоположной стороны.

### 3.6. Атака

1. Цель уничтожается и отправляется на кладбище своей стороны.
2. Атакующая фигура занимает клетку цели.
3. Тратятся все оставшиеся ОД, ход завершается.
4. Если атакующая фигура оказалась на своей линии повышения — повышение происходит (раздел 3.7) до передачи хода.

### 3.7. Повышение

Срабатывает **сразу**, как только фигура оказалась на своей линии повышения — движением, атакой или эффектом карты. Отложенного повышения нет.

- Треугольник → Квадрат. Квадрат → Круг. Круг не повышается (остаётся на линии, ничего не происходит).
- Старая фигура убирается с доски и **не попадает на кладбище**.
- Новая фигура ставится в **первую свободную клетку** при обходе стартовой зоны в порядке: `y=7` слева направо, затем `y=6` слева направо. Если свободных нет — то же по ряду `y=5`. Если и там нет — повышение отменяется, фигура остаётся на линии повышения без изменений.
- Выставление не стоит ОД и не считается действием.
- Повышённая фигура **в этот ход больше действовать не может** (её действие уже израсходовано на ход, приведший к повышению).

**Повышение врага** работает зеркально: линия повышения врага — `y = 7`, зона размещения — `y = 0` слева направо, затем `y = 1` слева направо, резервный ряд — `y = 2`.

### 3.8. Победа и поражение

- Все фигуры врага уничтожены → бой выигран.
- Все фигуры игрока уничтожены → ран окончен, экран итогов.
- Ничьей нет.

## 4. Структура рана

5 боёв подряд. Выжившие фигуры переносятся в следующий бой в том составе и количестве, в каком закончили предыдущий.

**Правило расстановки между боями.** Отсортировать фигуры игрока по убыванию ранга (Круг → Квадрат → Треугольник). Заполнять слоты строго в этом порядке:

```
(2,7) (5,7) (3,7) (4,7) (1,7) (6,7) (0,7) (7,7)
(2,6) (3,6) (4,6) (5,6) (1,6) (6,6) (0,6) (7,6)
(2,5) (3,5) (4,5) (5,5) (1,5) (6,5) (0,5) (7,5)
```

Стартовая расстановка первого боя (3.2) — частный случай этого правила.

**После каждого выигранного боя игрок получает +1 Треугольник.** Это единственная компенсация потерь. Без неё ран становится непроходимым после неудачного второго боя.

### 4.1. Волны противника

| Бой | Состав врага | Клетки |
|---|---|---|
| 1 | 3 Треугольника | (2,1), (3,1), (5,1) |
| 2 | 4 Треугольника, 1 Квадрат | Т: (1,1),(3,1),(4,1),(6,1); К: (3,0) |
| 3 | 4 Треугольника, 2 Квадрата | Т: (1,1),(2,1),(5,1),(6,1); К: (2,0),(5,0) |
| 4 | 5 Треугольников, 2 Квадрата, 1 Круг | Т: (1,1),(2,1),(3,1),(4,1),(6,1); К: (1,0),(6,0); О: (4,0) |
| 5 (босс) | 4 Треугольника, 2 Квадрата, **Проповедник** (Круг) | Т: (1,1),(2,1),(5,1),(6,1); К: (2,0),(5,0); Проповедник: (3,0) |

### 4.2. Босс

**Проповедник** — Круг с отдельным визуальным маркером (двойное кольцо, тлеющий красный внутренний свет) и собственным лейтмотивом из двух нот.

Способность: на **своём 3-м, 7-м и 11-м ходу** разыгрывает карту **Депрессия** — дальность передвижения и атаки всех Квадратов и Кругов игрока становится равной 1 на **3 ближайших хода игрока**. Разыгрывание показывается полноценной сценой карты (раздел 9.4), но карта принадлежит врагу и в пул игрока не попадает.

Если Проповедник уничтожен, способность больше не срабатывает, а активный эффект Депрессии снимается немедленно.

### 4.3. Драфт карт

- **Перед первым боем** игроку показывают 2 случайные карты из 5, он выбирает 1.
- **После каждого выигранного боя** (кроме последнего) показывают 2 случайные карты из ещё не взятых, он выбирает 1.
- К пятому бою в пуле 5 карт из 5.
- Экран драфта: две карты по центру на затемнённом фоне, наведение подсвечивает, клик выбирает. Никакого текста кроме названия и эффекта карты.

## 5. Карты Кармы

### 5.1. Общие правила

- **Период Кармы — 3 хода игрока.** Периоды: ходы 1–3, 4–6, 7–9 и так далее. Карта тянется **в начале последнего хода периода** — то есть на ходах 3, 6, 9, …
- Период, начатый розыгрышем карты с режимом «в свой ход», для целей длительности эффектов заканчивается **через 3 хода игрока** после розыгрыша. Любой эффект «до конца текущего Периода Кармы» действует ровно **3 хода игрока**, включая ход розыгрыша.
- Карты тянутся в открытую, эффект виден до применения.
- Таймеров розыгрыша и применения нет.
- Карта с режимом «сразу» разыгрывается немедленно после показа, по кнопке или клику.
- Карта с режимом «в свой ход» остаётся доступной до конца Периода Кармы; неразыгранная — сбрасывается.
- Если карта неприменима (нет целей), она **сбрасывается без эффекта** с надписью «Карта не может быть разыграна» на 1,2 с.
- «Считается за ход» означает: после разрешения эффекта ход игрока немедленно завершается.

### 5.2. Реестр карт

#### Линия смерти
- Режим: сразу. Считается за ход: **да**.
- Эффект: бросается `1d8`, определяется номер столбца `x = результат - 1`. **Все фигуры обеих сторон** в этом столбце уничтожаются и отправляются на кладбища своих сторон.
- Неприменима: никогда.

```
const x = randInt(0, 7);
for (const fig of allFigures()) if (fig.cell.x === x) destroy(fig);
endPlayerTurn();
```

#### Обстрел
- Режим: сразу. Считается за ход: **да**.
- Эффект: выбираются **8 различных случайных клеток** доски. Клетки подсвечиваются на 700 мс, затем все стоящие на них фигуры **обеих сторон** уничтожаются.
- Неприменима: никогда.

```
const cells = pickDistinctRandomCells(8);
highlight(cells, 700);
for (const c of cells) { const f = figureAt(c); if (f) destroy(f); }
endPlayerTurn();
```

#### Шпион
- Режим: сразу. Считается за ход: **нет**.
- Эффект: игрок кликает **одну фигуру врага**. Она переходит к игроку навсегда: меняется сторона, направление движения и атаки разворачивается.
- Если после смены владельца фигура стоит на линии повышения игрока (`y = 0`) — повышается по обычным правилам.
- Фигура **может действовать в этот же ход**.
- Неприменима: если у врага нет фигур (невозможно — бой был бы выигран).

#### Блицкриг
- Режим: в любой момент своего хода до конца Периода Кармы. Считается за ход: **нет**.
- Эффект: **первая фигура, которой игрок начнёт действовать после розыгрыша**, может совершить до 5 действий подряд. Для неё снимается правило «одна фигура — одно действие».
- ОД тратятся обычно; атака по-прежнему тратит все оставшиеся ОД и завершает ход.
- Эффект обрывается, если игрок подействовал любой другой фигурой, или если эта фигура повысилась.
- Неприменима: никогда.

#### Воскрешение
- Режим: сразу. Считается за ход: **нет**.
- Эффект: игрок выбирает одну фигуру со своего кладбища (любую, уничтоженную с начала **текущего боя**). Она возвращается на доску по правилу размещения из 3.7.
- Восстановленная фигура **может действовать в этот же ход**.
- Неприменима: если кладбище игрока пусто, или в стартовой зоне и ряду `y=5` нет свободных клеток.

### 5.3. Порядок разрешения

Если в один момент срабатывает несколько вещей, порядок строго такой:

1. Разрешение эффекта карты (уничтожения, перемещения, смены владельца).
2. Проверка повышений — все фигуры на линиях повышения, в порядке возрастания `x`.
3. Проверка условий победы и поражения.
4. Завершение хода, если карта считается за ход.

## 6. ИИ противника

Без поиска в глубину. Жадный алгоритм с приоритетами — детерминированный, читаемый, достаточный.

### 6.1. Ценность фигур

```
VALUE = { triangle: 10, square: 40, circle: 100 }
```

### 6.2. Алгоритм хода

Пока есть ОД и есть легальные действия:

1. **Убийство.** Собрать все легальные атаки. Если есть хотя бы одна — выбрать атаку с максимальной `VALUE[цель]`. При равенстве — цель с наименьшим `y` (ближе к линии повышения врага). Атаковать. Ход завершается.
2. **Повышение.** Если какая-то фигура врага может одним движением попасть на `y = 7` — сделать это движение.
3. **Позиционный ход.** Для каждого легального движения посчитать оценку и выполнить лучшее:

```
score = 12 * (to.y - from.y)                // враг наступает вниз: +12 за каждый пройденный ряд
      + 30 * countPlayerFiguresUnderAttackFrom(fig, to)
      + 20 * (canReachRow7In1MoveFrom(fig, to) ? 1 : 0)
      - 25 * (isUnderPlayerAttack(to) ? VALUE[fig.rank] / 10 : 0)
      -  8 * (countPlayerAttackersOf(to) >= 2 ? 1 : 0)
      + randInt(0, 3)                        // разрыв равенств, чтобы бои не были одинаковыми
```

`randInt(a, b)` — целое в диапазоне `[a, b]` включительно. Все проверки «под атакой» считаются по состоянию доски **после** гипотетического хода.

4. Если ни одного легального действия нет — ход завершается принудительно.

### 6.3. Ограничение, обязательное к соблюдению

ИИ **не должен ходить мгновенно**. Между его действиями пауза **420 мс**, чтобы игрок успевал прочитать происходящее. Ход ИИ полностью проигрывается анимациями по тем же правилам, что и ход игрока.

## 7. Визуальная спецификация

### 7.1. Холст и геометрия

- Логический размер холста **1280 × 720**. Масштабируется под окно с сохранением пропорций, поля — чёрные.
- Учитывать `devicePixelRatio` при создании контекста.
- Доска **плоская, вид сверху**. Никакой перспективы и изометрии — это экономит время и не даёт ошибок в хит-тесте.

| Объект | Геометрия |
|---|---|
| Доска | Квадрат 512 × 512, левый верхний угол (384, 96) |
| Клетка | 64 × 64 |
| Центр клетки | `(384 + x*64 + 32, 96 + y*64 + 32)` |
| Полоса ОД | 5 кругов r=7, шаг 26, центр по горизонтали, y = 648 |
| Кладбище игрока | Полоса слева от доски, x 300–370, снизу вверх |
| Кладбище врага | Полоса справа от доски, x 910–980, сверху вниз |
| Пул карт | Веер у левого края, x 40–260, y 300–500 |

### 7.2. Палитра

| Роль | Hex |
|---|---|
| Фон | `#0B0A0A` |
| Клетка тёмная | `#171514` |
| Клетка светлая | `#1F1C1A` |
| Шов между клетками | `#000000`, ширина 1 |
| Фигура игрока | `#EFE6D8` |
| Фигура врага | `#4A4643` |
| Кровь / угроза | `#8C1C13` |
| Свеча / повышение / Круг | `#D9A441` |
| Полынь / карма | `#2E6B5E` |
| Текст основной | `#EFE6D8` |
| Текст приглушённый | `#7A7370` |

**Правило:** на экране одновременно не более двух акцентных цветов. Кровь и свеча вместе — только в момент повышения фигуры, стоящей под ударом.

### 7.3. Как рисовать фигуры

Все фигуры рисуются в центре клетки. Под каждой — тень: `ctx.shadowColor = '#000'`, `shadowBlur = 12`, `shadowOffsetY = 4`.

| Ранг | Отрисовка |
|---|---|
| Треугольник | Равносторонний треугольник, радиус описанной окружности 22, вершина направлена «вперёд» своей стороны. Заливка цветом стороны. Обводка `rgba(0,0,0,0.4)`, 1,5 px |
| Квадрат | Скруглённый прямоугольник 40 × 40, радиус угла 4. Заливка цветом стороны. Внутренняя фаска: обводка `rgba(255,255,255,0.12)` шириной 2 по внутреннему периметру |
| Круг | Окружность r = 22, заливка цветом стороны. Внутри кольцо r = 12, обводка `#D9A441` шириной 3. Постоянное свечение: `shadowColor = '#D9A441'`, `shadowBlur = 16`, пульсация blur 12↔20 с периодом 3 с |
| Босс | Как Круг, но кольцо `#8C1C13`, второе кольцо r = 17 обводкой `#8C1C13` шириной 1,5, свечение красное |

Фигуры врага дополнительно получают обугленный край: поверх заливки — обводка `rgba(0,0,0,0.55)` шириной 3.

**Текстура кости** (только для фигур игрока): поверх заливки нарисовать 6 коротких линий случайной ориентации цветом `rgba(0,0,0,0.10)`, шириной 1. Позиции генерируются один раз при создании фигуры и не меняются — иначе фигура будет «кипеть».

### 7.4. Доска

- Клетки в шахматном порядке `#171514` / `#1F1C1A`. Разница почти неощутима — сетка читается по швам.
- Швы: линии `#000000` шириной 1 между клетками.
- **Линия повышения игрока** (`y = 0`): верхний край доски — полоса высотой 3 цветом `#D9A441`, свечение `shadowBlur = 20`. Это единственный тёплый элемент. Он объясняет цель без единого слова.
- Линия повышения врага (`y = 7`): такая же полоса цветом `#8C1C13`, свечение 12.
- **Освещение:** поверх доски — радиальный градиент от центра, от `rgba(255,240,220,0.06)` к прозрачному, радиус 400. Центр колеблется на ±8 px с периодом 6 с — свет «дышит».
- **Виньетка:** поверх всего холста радиальный градиент к `rgba(0,0,0,0.75)` по краям.
- **Зерно:** каждый кадр 400 случайных точек `rgba(255,255,255,0.015)` размером 1 px. Дёшево и убирает ощущение «плоского вектора».

### 7.5. Подсветки

| Что | Как |
|---|---|
| Клетки хода выбранной фигуры | Заливка `rgba(239,230,216,0.10)` + обводка `rgba(239,230,216,0.35)` 1,5 px. Появляются каскадом: задержка `14 мс × расстояние в клетках` от фигуры |
| Клетки атаки выбранной фигуры | Швы вокруг клетки наливаются `#8C1C13`, толщина 2, свечение 8 |
| Клетки под ударом врага | **Всегда включено.** Тонкая обводка `rgba(140,28,19,0.45)` 1 px по периметру клетки. Пересчитывается после каждого действия |
| Наведение на клетку | Заливка светлее на 6 % |
| Выбранная фигура | Масштаб 1,08, свечение цветом стороны, blur 14 |

Постоянная подсветка угрозы — обязательна. Смерть от того, что игрок не заметил угрозу, недопустима.

### 7.6. Карты

Карта — прямоугольник 180 × 260, радиус угла 6.

- Фон `#0B0A0A`, обводка `#2E6B5E` шириной 2, свечение полынное blur 12.
- Сверху — название капителью, трекинг 2 px, цвет `#EFE6D8`, 18 px.
- По центру — **гравюра-символ**, рисуется примитивами цветом `#2E6B5E`, область 100 × 100:
  - Линия смерти — вертикальный столб шириной 14 с расходящимися лучами
  - Обстрел — 8 точек r=5, разбросанных по сетке 3×3 без центра
  - Шпион — два треугольника вершинами навстречу, один залит, один контурный
  - Блицкриг — 5 стрелок в ряд, нарастающей длины
  - Воскрешение — круг с восходящей стрелкой внутри
- Снизу — текст эффекта, 13 px, цвет `#7A7370`, максимум 3 строки.

### 7.7. Интерфейс

Ни одной прямоугольной панели с рамкой. Всё живёт в темноте вокруг доски.

| Элемент | Решение |
|---|---|
| Очки действий | 5 кругов под доской. Полный — заливка `#D9A441`, свечение blur 10. Потраченный — обводка `rgba(217,164,65,0.25)`, заливки нет |
| Период Кармы | 3 засечки под полосой ОД. Заполняются полынным цветом по ходам. На третьей — вспышка и приход карты |
| Прогресс рана | 5 засечек в правом верхнем углу, пройденные залиты `#8C1C13` |
| Кнопка «Завершить ход» | Текст капителью в правом нижнем углу, без рамки. Неактивна (цвет `#3A3634`), пока не сделано ни одного действия |
| Кладбище | Уменьшенные до 0,5 фигуры, лежат стопкой. Не исчезают до конца боя |

**Типографика:** только системные стеки. Заголовки — `Georgia, 'Times New Roman', serif`, капитель, трекинг 2 px. Тело — `system-ui, -apple-system, 'Segoe UI', sans-serif`. Цифры — табличные (`font-variant-numeric: tabular-nums`). Минимальный кегль 14 px.

## 8. Аудиоспецификация

Всё синтезируется. Ни одного файла.

### 8.1. Примитивы в `synth.ts`

```ts
noiseBuffer(ctx, seconds)            // белый шум в AudioBuffer, генерируется один раз
env(param, {a, d, s, r, peak})       // ADSR через setValueAtTime/linearRamp/exponentialRamp
tone({type, freq, dur, gain, glide}) // осциллятор с огибающей и опциональным сдвигом частоты
noiseHit({dur, filter, q, gain})     // шумовой всплеск через band-pass
reverb(ctx, seconds, decay)          // ConvolverNode на затухающем шуме, генерируется один раз
```

**Обязательно:** мастер-цепочка `dryGain + reverbSend → compressor (DynamicsCompressor, threshold -18, ratio 4) → destination`. Без компрессора вау-моменты будут клиппить.

**Вариативность обязательна:** у каждого частого события питч и длительность рандомизируются на **±8 %**. Одинаковый звук на двухсотом убийстве убивает вау сильнее, чем его отсутствие.

### 8.2. Карта звуков

| Событие | Рецепт | Громкость |
|---|---|---|
| Наведение на фигуру | `noiseHit` 25 мс, band-pass 2400 Гц, Q 6 | −20 dB |
| Выбор фигуры | `tone` sine 90 Гц, 180 мс + `noiseHit` 30 мс band-pass 900 Гц | −12 dB |
| Показ зоны хода | На каждую клетку `noiseHit` 18 мс, band-pass `600 + 120 × расстояние` Гц, Q 8 | −24 dB |
| Передвижение | `noiseHit` 160 мс, band-pass со свипом 800 → 300 Гц + `tone` sine 70 Гц, 90 мс на приземлении | −10 dB |
| Невозможный ход | `tone` square 140 Гц, 70 мс, быстрый спад | −16 dB |
| Трата ОД | `noiseHit` 40 мс, high-pass 3000 Гц | −22 dB |
| **Удар (убийство)** | Слой 1: `tone` sine 120 → 40 Гц за 120 мс. Слой 2: `noiseHit` 90 мс, band-pass 1800 Гц, Q 3. Слой 3: `noiseHit` 400 мс, low-pass 400 Гц, ревер-сенд 0,5 | −3 dB |
| Убийство Круга | То же + `tone` triangle 660 Гц, 900 мс, медленное затухание, ревер-сенд 0,8 | −3 dB |
| Приход карты | Колокол: 5 синусов на `f × [1, 2.76, 5.40, 8.93, 13.34]`, база 180 Гц, разное время затухания (2,4 / 1,8 / 1,2 / 0,8 / 0,5 с) | −8 dB |
| Сгорание карты | `noiseHit` 800 мс, band-pass со свипом 4000 → 200 Гц | −14 dB |
| **Повышение ранга** | 0 мс: тишина (мастер в 0 за 40 мс). 300 мс: `tone` sine 55 Гц, 1,2 с. 600 мс: «хор» — 6 пил на 220 Гц с детюном `[-14,-9,-4,+4,+9,+14]` центов, low-pass 1800, нарастание 700 мс, вибрато 5 Гц глубиной 6 центов. 1000 мс: удар — `noiseHit` 200 мс + `tone` sine 80 Гц, ревер-сенд 1,0 | −2 dB на пике |
| Линия смерти | 0 мс: колокол на 90 Гц, реверснутая огибающая 400 мс. 1400 мс: `noiseHit` 1,2 с, low-pass 300 Гц, ревер-сенд 1,0 | −2 dB |
| Обстрел | 8 попаданий с шагом 60 мс: `noiseHit` 120 мс, band-pass `1200 + rnd(800)` Гц | −6 dB |
| Появление Круга врага | `tone` sine 44 Гц, 1,6 с + шумовой свип вверх | −8 dB |
| Лейтмотив босса | Две ноты: `tone` triangle 146,8 Гц (D3) 400 мс → 138,6 Гц (C♯3) 900 мс, ревер-сенд 0,7 | −8 dB |
| Мало фигур (≤2) | Сердцебиение: пара `tone` sine 50 Гц по 80 мс с паузой 180 мс, повтор каждые 2 с | −18 dB |
| Победа в бою | Восходящая тройка `tone` sine 220 / 293,7 / 440 Гц по 300 мс, ревер 1,0 | −6 dB |
| Поражение | Одна `tone` sine 55 Гц, 3 с, медленное затухание, ревер 1,0 | −8 dB |

### 8.3. Музыка

Один процедурный трек, три слоя, включаются по состоянию боя, не по таймеру.

| Слой | Когда | Содержание |
|---|---|---|
| Основание | Всегда | Дрон: 2 пилы 55 Гц с детюном 6 центов через low-pass 400 Гц, амплитуда колеблется LFO 0,08 Гц. Плюс `noiseHit` 600 мс low-pass 200 Гц каждые 4 с |
| Обряд | С первого убийства в бою | Перкуссия из шума, 60 BPM, узор `x . . x . x . .` по восьмым, band-pass 700 Гц |
| Хор | Когда у любой из сторон осталось ≤ 2 фигур, и во всех вау-сценах | Стопка расстроенных пил на нотах фригийского лада от A: `A C D E F`, нота меняется каждые 8 секунд, long reverb |

- Переходы между слоями — кроссфейд **2 секунды**, без резов.
- В момент повышения ранга музыка **уходит в ноль за 40 мс** и возвращается на слой выше через 1,4 с. Это единственный способ сделать сцену по-настоящему громкой.
- Между боями — только Основание.
- На экране поражения — музыки нет, только одна затухающая нота. Игрок должен хотеть нажать рестарт, а не отгоревать.

## 9. Juice — тайминги

Все числа обязательны к соблюдению. Это не «полировка потом», это спецификация.

### 9.1. Принципы

1. Каждое действие откликается в трёх каналах: **движение, свет, звук**. Действие без всех трёх не считается сделанным.
2. Сила отклика пропорциональна значимости: наведение — 60 мс, повышение ранга — 1,4 с. Между ними шкала, и её нужно соблюдать.
3. Отклик мгновенный, последствие может ждать. Ввод подтверждается в тот же кадр.
4. Анимации прерываемы — кроме вау-сцен (9.3, 9.4).
5. Тишина — инструмент. Пауза 200 мс перед ударом делает его громче любого микса.

### 9.2. Базовые действия

| Событие | Движение | Свет и партиклы |
|---|---|---|
| Наведение | Масштаб 1,04 за 60 мс, ease-out | Контур на 30 % |
| Выбор фигуры | Масштаб 1,08 за 80 мс, поворот 2° | Свечение, тень удлиняется на 30 % |
| Зона хода | — | Каскад клеток, 14 мс задержки на клетку |
| Передвижение | 140 мс, ease-out-back с перелётом 6 % | Шлейф из 8 частиц пыли, тень отстаёт на 30 мс |
| Невозможный ход | Тряска фигуры ±6 px, 120 мс | Красная вспышка контура |
| Трата ОД | — | Круг ОД гаснет за 200 мс, вверх уходит 3 частицы дыма |
| Конец хода | Доска отдаляется на 1 % за 200 мс | Свет над доской мигает |

### 9.3. Атака — эталонная последовательность

Самое частое значимое событие. Должно ощущаться дорого и на двухсотый раз.

| Время | Что происходит |
|---|---|
| 0 мс | Клик. Фигура дёргается назад на 8 % — замах |
| 90 мс | Рывок к цели за 60 мс, резкий ease-in. Шлейф вытягивается |
| 150 мс | **Hitstop 110 мс.** Вся анимация замирает. Звука нет. Белая вспышка на 1 кадр |
| 260 мс | Мир оживает. Тряска камеры 7 px с затуханием 180 мс. Звук удара |
| 260 мс | Цель распадается: **14 осколков**, разлёт по дуге, скорость 60–140 px/с, гравитация 300 px/с², оседание 500 мс |
| 300 мс | Красное пятно на швах вокруг клетки, растекается 400 мс, **остаётся до конца боя** |
| 380 мс | Атакующая занимает клетку. Оставшиеся ОД гаснут подряд, 40 мс между |
| 600 мс | Осколки долетают до кладбища и падают со стуком |

Убийство Круга: hitstop **180 мс**, тряска **12 px**, вспышка золотом, отдельный звук.

### 9.4. Вау-сцены

Прерывать нельзя. Ввод заблокирован. **При повторе за один ран длительность сокращается на 40 %** — первый раз полный, дальше быстрее.

#### Повышение ранга — 1400 мс

| Время | Что происходит |
|---|---|
| 0 | Фигура коснулась золотой линии. **Мгновенная тишина** — мастер в ноль за 40 мс |
| 80 | Всё, кроме фигуры, гаснет до 15 % яркости. Камера наезжает до 1,25 за 400 мс |
| 300 | Фигура зависает. Из золотой линии поднимается столб света шириной 40 px. Низкая нота |
| 600 | Фигура **трескается**: 7 процедурных линий-трещин, изнутри бьёт свет `#D9A441`. Нарастает хор |
| 850 | Распад на 12 осколков. Осколки зависают, вращаясь, — 150 мс невесомости |
| 1000 | Осколки схлопываются внутрь. **Вспышка на весь экран.** Удар с ревером 2 с |
| 1100 | Появляется фигура нового ранга в клетке размещения. Ударная волна по доске, тряска 8 px |
| 1400 | Камера возвращается, свет восстанавливается, музыка входит слоем выше |

**Первое повышение за ран** — 1800 мс, плюс золотая пыль по всей доске (60 частиц).

#### Линия смерти — 2200 мс

| Время | Что происходит |
|---|---|
| 0 | Карта переворачивается, символ горит красным. Реверснутый колокол |
| 400 | Кубик физически катится по доске и останавливается. Единственное место в игре, где кубик показан |
| 700 | Выбранный столбец наливается красным снизу вверх за 500 мс. **Игрок успевает понять, кого потеряет — ужас должен опередить событие** |
| 1200 | Тишина 200 мс |
| 1400 | Столб света бьёт сверху вниз. Hitstop 200 мс. Все фигуры в столбце распадаются одновременно. Тряска 16 px |
| 2000 | Оседает пепел. Долгое эхо. Музыка уходит на слой ниже |

#### Обстрел — 1600 мс

| Время | Что происходит |
|---|---|
| 0 | Карта сгорает. Небо над доской темнеет |
| 300 | 8 клеток загораются красным контуром, пульсируют |
| 1000 | Попадания с шагом 60 мс: вспышка, кратер, распад фигуры. Тряска 6 px на каждое, накапливается |
| 1600 | Пыль оседает, доска в кратерах до конца боя |

### 9.5. Камера

- База: статична, доска целиком, дыхание — колебание масштаба 0,5 % с периодом 8 с.
- Тряска всегда с затуханием, никогда линейная. Три силы: **7 px** (убийство), **12 px** (Круг, босс), **16 px** (вау-сцена).
- Наезд только в вау-сценах. Никогда во время обычного хода.
- Смерть последней фигуры: медленный наезд на неё 2 с, затемнение, пауза 800 мс перед экраном итогов.

### 9.6. Партиклы

Шесть систем, все на канвасе, пул объектов, максимум 400 частиц одновременно.

| Система | Параметры |
|---|---|
| Осколки кости | 12–14 шт, треугольники 3–7 px, цвет фигуры, скорость 60–140 px/с, гравитация 300, вращение, жизнь 900 мс |

### 9.7. Первые десять секунд

Отдельно спроектированная последовательность. Задача: за 10 секунд от открытия вкладки довести до первого хода.

| Время | Что видит игрок |
|---|---|
| 0–1 с | Чёрный экран. Один звук — вдох (шумовой свип вверх, 900 мс). Инициализация спрятана за эту секунду |
| 1–3 с | Из темноты проявляется свет над доской. Доска возникает как высвеченный из мрака объект |
| 3–5 с | Фигуры игрока **падают на доску** одна за другой, 90 мс между, с ударом. Шесть ударов складываются в ритм |
| 5–6 с | Фигуры врага проступают из темноты беззвучно. Контраст с твоим появлением намеренный |
| 6–7 с | Золотая линия зажигается. Цель показана светом, без слов |
| 7–8 с | 5 кругов ОД загораются. Наведение уже откликается |
| 8–10 с | Первый ход |

**Туториала нет.** Обучение встроено в отклик: подсвеченные клетки хода, красный контур угрозы, золотая линия цели. Единственный текст за первый бой — название карты при её приходе.

## 10. Порядок реализации

Шесть этапов. **После каждого игра запускается и в неё можно играть.** Не переходить к следующему, пока предыдущий не играется.

| Этап | Что делаем | Играбельно после этапа |
|---|---|---|
| 1 | `types.ts`, `board.ts`, `rules.ts`, `battle.ts`, минимальный `renderer.ts`. Доска, фигуры, легальные ходы, атака, ОД, ход игрока. Отрисовка примитивами без эффектов | Можно двигать фигуры и убивать неподвижного врага |
| 2 | `ai.ts`, условия победы и поражения, `run.ts` с цепочкой 5 боёв и волнами | Полный ран проходится от начала до конца |
| 3 | Повышение, кладбище, перенос выживших между боями, +1 Треугольник за победу | Полная механическая игра. **С этого момента баланс можно тестировать** |
| 4 | `cards.ts` — 5 карт, Период Кармы, драфт, босс с Депрессией | Все механики на месте |
| 5 | `animator.ts`, `particles.ts`, `camera.ts`, `scenes.ts` — весь раздел 9 | Игра ощущается |
| 6 | `synth.ts`, `sfx.ts`, `music.ts` — весь раздел 8. Плюс первые 10 секунд | Готово |

Этапы 5 и 6 — **не опциональные**. Игра без них считается несделанной: вау-эффект и есть задача.

### 10.1. Тесты

Юнит-тесты обязательны для `rules.ts` и `cards.ts`. Тестируется **ожидаемое поведение по этой спецификации**, а не то, что написалось в коде.

Минимальный набор:
- Треугольник не ходит назад и вбок; ходит вперёд на 1.
- Квадрат не ходит назад; ходит на 1–3 в пяти направлениях; не перепрыгивает фигуры.
- Круг ходит во все стороны на 1–5; не перепрыгивает.
- Атака тратит все оставшиеся ОД и завершает ход.
- Фигура не может действовать дважды за ход (кроме Блицкрига).
- Повышение срабатывает мгновенно и ставит фигуру по правилу размещения.
- Повышение отменяется, если нет свободных клеток.
- Линия смерти убивает фигуры **обеих** сторон в столбце.
- Воскрешение неприменимо при пустом кладбище.
- Шпион разворачивает направление фигуры.
- Победа объявляется при нуле фигур врага.

## 11. Definition of Done

Прототип сдан, если по каждому пункту «да»:

**Механика**
- [ ] Ран из 5 боёв проходится от начала до конца без ошибок в консоли
- [ ] Все 5 карт реализованы и работают по разделу 5
- [ ] Все три ранга и повышение работают по разделу 3.7
- [ ] Босс разыгрывает Депрессию на 3, 7 и 11 ходу
- [ ] ИИ не делает откровенно глупых ходов: не подставляет Круг под Треугольник без размена
- [ ] Юнит-тесты из 10.1 зелёные

**Ощущение**
- [ ] Первое убийство вызывает физическую реакцию у тестера
- [ ] Первое повышение ранга вызывает реакцию **вслух**
- [ ] После поражения рестарт нажимается быстрее чем за 3 секунды
- [ ] Со звуком и без звука — это две разные игры, разница очевидна
- [ ] Игру хочется снять на видео

**Техника**
- [ ] Ноль внешних файлов: ни картинок, ни звуков, ни шрифтов
- [ ] Ноль сетевых запросов в рантайме
- [ ] 60 FPS не падает ни в одной вау-сцене
- [ ] Время от открытия страницы до первого хода — меньше 10 секунд, из них загрузка меньше 1 секунды
- [ ] Работает в Chrome, Firefox, Safari
- [ ] `core/` не импортирует ничего из `view/` и `audio/`

## 12. Экран итогов

Появляется через 800 мс после гибели последней фигуры игрока или после победы в пятом бою.

- Фон — чёрный, доска не видна.
- Строки капителью, цвет `#EFE6D8`, по центру: исход («ПАЛ» или «ОБРЯД ЗАВЕРШЁН»), номер боя, число ходов, число убийств, число повышений, список собранных карт символами.
- Внизу — «ЗАНОВО», цвет `#8C1C13`, увеличивается на 4 % при наведении.
- Клик или Пробел мгновенно начинает новый ран с нуля: стартовый отряд, пустой пул, драфт.
- **Цель — 2 секунды между поражением и следующим ходом.** Никаких промежуточных меню, никаких подтверждений.

## 13. Крайние случаи

Решения приняты заранее. Не изобретать свои.

| Ситуация | Решение |
|---|---|
| Повышение, но нет свободных клеток в зонах `y=7,6,5` | Повышение отменяется, фигура остаётся на линии повышения без изменений |
| Линия смерти уничтожает последние фигуры обеих сторон | Побеждает игрок |
| Линия смерти уничтожает все фигуры игрока | Поражение |
| У игрока нет ни одного легального действия в начале хода | Ход автоматически передаётся врагу. Поражения нет |
| У ИИ нет ни одного легального действия | Ход передаётся игроку |
| Обстрел выбрал клетку, где нет фигуры | Ничего не происходит, кратер рисуется |
| Шпион забирает фигуру, стоящую на `y=0` | После смены владельца фигура немедленно повышается |
| Блицкриг разыгран, но игрок закончил ход первой же атакой | Карта потрачена, эффект не возвращается |
| Блицкриг активен, фигура повысилась | Эффект обрывается, ход продолжается по обычным правилам |
| Воскрешение при пустом кладбище | Карта сбрасывается с сообщением «Карта не может быть разыграна» |
| Депрессия активна, Проповедник убит | Эффект снимается немедленно |
| Карта пришла на ходу, где игрок уже не может действовать | Карта разыгрывается, затем ход передаётся |
| Две карты в один Период Кармы | Невозможно: карта тянется строго раз в 3 хода |
| Игрок кликает во время вау-сцены | Клик игнорируется. Сцену прервать нельзя |
| Окно изменило размер во время анимации | Пересчитать масштаб, анимации продолжаются |
| Вкладка ушла в фон | Приостановить `requestAnimationFrame` и звук, при возврате продолжить |
