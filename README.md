# Jedibo — WOW-прототип

Пошаговая тактическая игра на клетчатом поле (Треугольник/Квадрат/Круг) с колодой Карт Кармы,
периодически ломающих детерминированные правила.

## Играть в браузере

- Хаб: https://azzazelloqq.github.io/TestJeDiBo/
- Jedibo (v1): https://azzazelloqq.github.io/TestJeDiBo/jedibo/
- Обряд / RITE (v2): https://azzazelloqq.github.io/TestJeDiBo/rite/

Ссылки оживают после деплоя GitHub Pages с ветки `main`.

## Версии

- **[v1-wow-slice](v1-wow-slice/index.html)** — первый vertical slice по брифу: полные правила
  (движение/атака фигур, ОД, повышение ранга), полная колода из 6 карт кармы с фирменной подачей
  для каждой (свой цвет, иконка, сигнатурный визуальный эффект), простой автономный ИИ-оппонент,
  процедурный звук (Web Audio, без файлов-ассетов), screen shake / вспышки / частицы на удар и смерть,
  комбо-камера для Блицкрига.

- **[v2-rite](v2-rite/SPEC.md)** — RITE: отдельная полная переработка по новому ТЗ (см. `v2-rite/SPEC.md`),
  реализуется поэтапно (Vite + TypeScript, `core/` без зависимостей от рендера и звука). В отличие от
  v1, это не один HTML-файл, а полноценный проект со своим `package.json`.

Каждая следующая версия будет добавляться отдельной папкой рядом, без перезаписи предыдущих.

## Как запустить локально

- **v1-wow-slice**: открыть `index.html` напрямую в браузере (двойной клик или `file://`),
  либо поднять любой статический сервер в папке версии.
- **v2-rite**: `cd v2-rite && npm install && npm run dev` (нужен Vite dev-сервер, статикой не откроется).
