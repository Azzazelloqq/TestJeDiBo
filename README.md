# Jedibo — WOW-прототип

Пошаговая тактическая игра на клетчатом поле (Треугольник/Квадрат/Круг) с колодой Карт Кармы,
периодически ломающих детерминированные правила. Один HTML-файл, открывается прямо в браузере,
без установки и без бэкенда.

## Версии

- **[v1-wow-slice](v1-wow-slice/index.html)** — первый vertical slice по брифу: полные правила
  (движение/атака фигур, ОД, повышение ранга), полная колода из 6 карт кармы с фирменной подачей
  для каждой (свой цвет, иконка, сигнатурный визуальный эффект), простой автономный ИИ-оппонент,
  процедурный звук (Web Audio, без файлов-ассетов), screen shake / вспышки / частицы на удар и смерть,
  комбо-камера для Блицкрига.

Каждая следующая версия будет добавляться отдельной папкой рядом, без перезаписи предыдущих.

## Как запустить

Открыть `index.html` нужной версии напрямую в браузере (двойной клик или `file://`),
либо поднять любой статический сервер в папке версии.
